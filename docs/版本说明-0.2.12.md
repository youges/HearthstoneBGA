# 0.2.12：无目标法术与重叠香蕉手牌

日期：2026-11-03。开发测试版，包含此前 2026-10-27 的招募识别校准补丁；该补丁保留独立说明。

本次现场确认两类问题：招募新人使用“随机获得一张等级1的随从牌”的说明，旧版没有覆盖该文本；多张香蕉的绿色边框相连，旧检测把过宽轮廓过滤掉，出现有手牌却识别为 0 张。钻探原油提高铸币上限的说明也曾被识别为未知。

按用户指定规则，已确认是法术后，“随机”优先于“发现”，按无指向释放；“使你的随从”同样按无指向释放；仅“发现”进入施放后的选择流程；其余未知效果默认尝试无指向释放。香蕉及可识别的单体增益仍选随从目标，主厨甄选保留已有专门流程。无法确认牌的类型时继续读取，不把未知随从当成法术。

无目标法术拖到施法区域后，等待原牌图像消耗或发现选择完成的连续可信反馈，再刷新手牌读取额度。获取新牌导致手牌数量不变时可以继续；短暂少检测一张、原牌仍在时不能证明成功。空手牌需要三帧确认。实际弹出选择界面时，即使文字未读到“发现”或按随机分类，也处理选择。意外目标箭头不会盲点随从，等待超时保存异常。

重叠手牌增加局部放大费用标记识别，只提供悬停候选，不直接授权出牌；收起说明后仍需两帧图像确认同一张牌。香蕉在场面数量未知时可先拖出，随后依据真实箭头和合法高亮选取友方随从；未找到合法目标时有超时处理。施放完成可结合原牌消失确认，避免候选数量波动阻止后续施法。

买入、三连等动画导致手牌外观变化时，同一位置允许重新读取一次说明，并用新图像重新确认两帧，不沿用旧类型出牌。随机偷取使手牌数量不变时，结合连续确认的商店数量减少刷新手牌读取额度。
