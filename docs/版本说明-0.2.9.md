# 0.2.9：异常后自动认输并重开

功能完成日期：2026-10-25，开发测试版。本次同时公开同步 0.2.5—0.2.8 的修复，各小版本独立说明见下方链接。

运行设置增加“异常后自动认输并重开”和“连续异常认输上限（局）”。公开下载包默认关闭自动认输，并保留只观察模式；需要此功能时在设置中开启。

已确认处于对局后，连续三次操作没有反馈、目标选择失败或局内识别超时，可触发恢复。先保存截图、对局 ID 和原因，再打开 Esc 菜单；识别菜单后点击认输，识别确认框后确认。认输后停止其他游戏操作，记录结算并确认稳定大厅，再按原有局数设置重新匹配。

菜单、认输与确认各最多三次尝试，恢复等待有 90 秒超时。默认连续三局异常认输后先保存第三局记录再暂停；正常完成一局会清零连续异常计数。认证、断线重连、失去前台、缺少校准和运行库错误不主动触发异常认输，手动暂停与停止继续有效。

历史记录新增“异常自动认输”，悬停结束原因可查看具体问题；CSV 导出包含 `recovery_reason`。数据库自动追加空原因字段，保留旧记录原字段；读取不到的名次与分数仍留空。

验证：本机完整测试 316 项、实际 EXE 的 75 组截图回放及 GUI、OCR/运行库自检通过。新 EXE 另以合成观测演练真实引擎的“失败三次→Esc→认输→确认→记录结算→大厅→再次匹配”，不操作真实游戏；真实异常认输重开尚未实战验证。公共仓库不包含私人截图，相关回归在 CI 中跳过。
