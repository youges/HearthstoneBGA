# 实机测试说明

2026-10-18，在本机使用从 GitHub 下载并校验的 0.2.3 Windows 程序，完成一局正常对局。0.2.4 沿用同一识别与操作逻辑，不将此结果冒称为 0.2.4 的新一局测试。

- 自动从已打开的战网启动炉石，进入大厅、匹配，并选择中间实际可选的英雄。
- 实际 7/7 画面读到 7，购买随从后读到 4/7，并保存操作反馈。旧版预处理在同一保存截图上仍会读到未知，新版读到 7。
- 日志确认 10 次购买、14 次出牌、5 次升级、3 次卖出和 2 次局内选择的成功反馈，升级包含四升五及五升六。
- 对局正常结束后记录名次和可靠积分，回到大厅，按单局测试配置停止。
- 招募阶段的金币采样中，动画模糊和放大手牌遮挡时出现空值；画面恢复后继续识别。未将空值编造为 0，也未重现稳定 7/7 画面导致整段招募跳过的问题。

本次仍有手牌类型不明确时跳过、短暂失去前台后自动恢复的提示。单局结果不能证明所有卡牌、策略、长期循环和其他电脑均可靠。连续多张指向性法术仍需独立的真实场景验收。

完整个人日志和截图仅留在测试机器，公开仓库只保留本说明。

## 0.2.5—0.2.9 补充验证

0.2.5 通过失败结算图片和十二局连续结算离线模拟；0.2.6 通过两选一卡牌多个时刻回放；0.2.7 使用实际 EXE 自动关闭一次活动任务并确认主菜单；0.2.8 通过技能选择图片及引擎流程回归；0.2.9 通过异常认输重开流程的合成观测演练。各版完整结果分别列在独立版本说明。

最终本机完整测试 316 项、冻结 EXE 图像回放 75 组通过。合成观测演练和截图回放不计作真实游戏输入；尚未实战验证异常自动认输后重开，也不代表跨电脑长期无人值守已验收。

## 0.2.10—0.2.11 补充验证

0.2.10 完整测试 337 项及冻结 EXE 81 组回放通过，覆盖混合手牌候选数量变化；0.2.11 完整测试 362 项及冻结 EXE 85 组回放通过，覆盖主厨甄选判型、合法目标选择和获取后手牌总数不变的完成反馈。两版均另通过无真实游戏输入的冻结引擎自检。新版混合手牌与主厨甄选的专项实战验收仍待完成，详见各自版本说明。
