# 酒馆助手使用说明

版本：0.2.2。适用于 Windows 桌面版《炉石传说：酒馆战棋》。

## 1. 开始之前

需要 Windows 10/11 的 64 位电脑、已安装的暴雪战网与炉石，以及可以正常登录的账号。程序不负责输入密码、验证码或处理账号验证。

推荐使用中文游戏界面、窗口模式、1280×720 以上的游戏客户区。客户区低于 960×540 物理像素时会拒绝自动操作。分辨率适配不代表所有游戏语言、布局和画质都能通用。

## 2. 安装和打开

1. 下载 Windows 便携 ZIP，解压到一个可写入的文件夹，例如 `D:\Games\HearthstoneBGA`。
2. 保留整个文件夹，不要单独移动 EXE，也不要删除 `_internal`、`assets`、`profiles`。
3. 双击 `HearthstoneBGA.exe`。便携版不需要额外安装 Python。
4. 第一次识别会初始化 OCR，通常比后续识别慢。等待日志出现运行状态即可。

从源码运行时，项目根目录的 `启动助手.cmd` 会优先打开打包 EXE，没有 EXE 时使用项目虚拟环境。新下载的源码需要先按 README 安装依赖。

## 3. 首次运行

1. 先手动打开战网，完成登录，选中《炉石传说》页面。
2. 打开助手“运行设置”。战网路径通常会自动填入。未找到时点击“自动检测”；仍未找到时点击“选择…”，找到战网启动 EXE。
3. 保留“自动适配分辨率与窗口比例”。符合校准比例的 16:9 全屏会保持原尺寸；其他全屏比例请切换窗口模式。
4. 新电脑先开启“只观察画面，不发送操作”，保存设置，回到首页点击“启动”。
5. 检查预览和状态是否对应当前游戏。只观察时不会购买、出牌或调整游戏窗口；需要时先手动把游戏调成接近 16:9。
6. 点击“停止”，确认本机布局可以识别。取消只观察，首次把“最多完成局数”设为 1，关闭测试认输，再保存并启动。
7. 运行一局后查看记录。确认正常后，最多局数改为 0 即可持续运行。

打开助手本身不会自动开始对局，需要点击“启动”。

## 4. 三个页面

### 运行概览

上方显示当前状态、本次完成局数和最近分差。中间显示最近采集的游戏画面与日志。下方显示历史记录，点击“导出 CSV”可以选择保存位置。

启动后助手会最小化，给游戏让出前台。预览是最近采集画面，程序暂停时不会持续刷新，因此不能用旧预览判断游戏当前状态。

### 界面校准

用于检查和调整已有布局。正常情况下先尝试内置 PC 布局，不需要逐项重新校准。

| 按钮 | 用法 |
| --- | --- |
| 导入客户区截图 | 选择纯游戏客户区图片，不要包含桌面边框 |
| 3 秒后采集目标画面 | 先选择游戏或战网类型；倒计时结束会激活目标并采集 |
| 保存此校准项 | 点位选中心，区域和模板用拖动框选，再保存 |
| 测试当前截图识别 | 查看状态、可信度、数值和识别到的卡牌位置 |
| 检查并完成校准 | 检查必需项；缺项时列出清单，完整后允许真实运行 |

保存任意校准项后，需要再次点击“检查并完成校准”。完成标志只表示必需项齐全，不能替代实际识别验证。模板选择稳定、独特的文字或图标，避开动画、纯色和随机英雄画像。

### 运行设置

按“客户端”“运行与窗口”“购买与出牌”“识别与等待”“测试选项”分组。修改后点击底部“保存设置”。

## 5. 常用设置

| 设置 | 作用与建议 |
| --- | --- |
| 只观察画面 | 新电脑第一次使用建议开启；开启时不发送游戏操作 |
| 自动启动战网 | 没有战网窗口时，从检测到的路径启动 |
| 启动时激活目标窗口 | 运行时把战网或游戏放到前台 |
| 失焦后自动恢复前台 | 键鼠空闲 2 秒后尝试恢复；避免在挂机时操作其他窗口 |
| 自动适配分辨率 | 符合校准比例的全屏保持原尺寸；普通窗口按校准比例调整至显示器工作区 |
| 最多完成局数 | 1 适合首次检验，0 表示不限局数 |
| 中间英雄偏好 | 2 为中间左侧，3 为中间右侧；仍需识别实际可选状态 |
| 读取手牌 | 读取牌面后区分已支持的随从和法术，建议开启 |
| 测试购买法术 | 测试功能，按限制购买低费法术；不等于支持所有法术 |
| 满场自动卖出腾位 | 卖出最左随从，不判断强弱；必须同时开启读牌 |
| 允许升级的最高费用 | 升本费用上限，不是目标酒馆等级；最高 30 |
| 升级后至少保留金币 | 控制升本经济；满场时可不保留以避免卡本 |
| 每回合动作上限 | 防止同一回合重复操作过多 |
| 识别间隔、动作间隔 | 单位为秒；过低不一定更快，可能增加负载 |
| 稳定帧数 | 连续识别一致后再操作，建议保留默认值 |
| 未知/加载超时 | 状态长期无法确认时提示处理 |
| 测试主动认输 | 仅用于流程测试，正常挂机应关闭 |

## 6. 换电脑与显示器

复制整个便携文件夹。新电脑路径失效时会重新检测战网。不要将旧电脑的战网目录当作必须照搬的路径。

自动适配读取游戏所在显示器的可用空间，计算客户区可用大小，保持校准比例。它不修改 Windows 分辨率或显示缩放。输入按客户区坐标换算，窗口变化后会重新识别，旧操作不继续执行。

0.2.1 会检查窗口样式和物理客户区，覆盖整个显示器且符合校准比例的全屏直接使用，不扣除任务栏、不尝试缩小。全屏比例不符合校准、游戏禁止调整窗口尺寸、屏幕空间过小或窗口被其他软件遮挡时，仍可能需要切换窗口模式、关闭覆盖层并检查日志。Windows 设置变化、游戏补丁、界面语言或布局变化仍可能需要重新校准。

## 7. 暂停、继续和停止

- 按 F8 或点击“暂停”：暂时不再执行操作。
- 点击“继续”：重新识别画面，再继续运行。
- 按 F9 或点击“停止”：结束本次运行。
- 正常达到局数后会停止并恢复助手窗口。

自动恢复前台不会解除主动暂停。停止程序不会保证当前对局已经结束；中途停止的记录会标为未完成。

## 8. 对局与记录

基础流程包含战网启动、进入游戏、战棋大厅、匹配、选中间可用英雄、买牌、出牌、升本、处理已支持的选择、结算和重新开始。

0.2.2 会在确认手牌消耗且目标选择结束后，重新识别剩余手牌，继续使用下一张已支持的指向性法术。目标箭头仍在时先选目标；未成功施放时不会无限重试。需要开启“读取手牌”。

记录字段包括开始时间、名次、结算总分、分差、结束原因、读取状态和英雄位置。读不到的字段留空，显示“—”。测试主动认输和正常结束分开记录。“截图补读完整”表示后来用已保存画面补读，不等同于原始运行全部自动成功。

## 9. 文件位置

便携版所有运行文件位于 EXE 同级目录：

- `data/settings.json`：运行设置。
- `data/matches.sqlite3`：对局记录。
- `data/logs`：日志。
- `data/screenshots`：识别与操作证据。
- `profiles/pc-integration.json`：内置 PC 布局及完成标志。
- `assets/templates`：识别模板。
- `docs`：使用与功能文档。

源码和便携版各自有独立的 `data`。升级前先备份自己的设置、记录和校准。公开分享时不要直接上传整个个人运行目录。

## 10. 常见问题

**启动后只显示画面，没有操作。** 检查是否开启了只观察模式，或程序已经暂停。真实运行还需要校准完成。

**提示目标不在前台。** 切回游戏，或开启自动恢复前台并等待键鼠空闲。如果已经主动暂停，还需点击“继续”。

**提示窗口未接受适配尺寸。** 先确认使用 0.2.1 或更新版本，旧版存在全屏误判问题。仍出现时切换窗口模式。不要强行把不同布局截图拉伸后当作校准成功。

**战网路径没有检测到。** 先打开战网再检测，或者手动选择其安装目录中的 `Battle.net Launcher.exe`/`Battle.net.exe`。特殊便携安装或未写注册表的安装可能需要手动选择。

**牌没有打出或升本没有发生。** 查看日志是否读取到金币、酒馆等级、牌型，以及是否处于招募阶段。未知信息会导致跳过，程序不会假设识别成功。

**7/7 金币时暂时不操作。** 已复现 OCR 将 7/7 识别为 L/L，导致金币未知。本版仍未修复，可能跳过该招募回合；不要将其理解为没有金币。

**更新后识别错误。** 先只观察并保存当前客户区截图，再在校准页测试识别。游戏布局改变后旧模板可能失效。

**能保证换电脑立即无人值守吗？** 不能。已验证多尺寸图像和本机原生窗口适配，但尚未完成另一台电脑上的完整对局验收。
