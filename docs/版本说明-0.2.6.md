# 0.2.6：无标题两选一卡牌识别修复

功能完成日期：2026-10-22。本小版本的改动随 0.2.9 同步到公开仓库。

连续完成九局后，第十局触发无标题两选一卡牌界面，旧版误读后方酒馆并连续升本失败。现通过两张可选卡的绿色边框、尺寸、对齐及对称位置识别，按实际卡牌中心选择左侧选项；选择完成前停止升本和购物。

仅在 PC 酒馆背景已由模板确认、旧选择模板未命中时启用补充识别。是否需要后续目标只读取所选卡牌说明，忽略底部其他手牌文字。菜单、确认框和公告仍优先处理；缺少已校准选择位置时阻止点击。回放报告增加实际目标坐标。

验证：当时本机完整测试 232 项通过，新 EXE 的 GUI、OCR/运行库自检及 47 组截图回放通过。覆盖弹窗多个时刻的四种尺寸、手牌悬停等负例、模态优先级和选择前后引擎顺序；未另跑长时间真实连续对局。
