# 0.2.7：进入游戏时自动关闭活动任务弹窗

功能完成日期：2026-10-24。本小版本的改动随 0.2.9 同步到公开仓库。

增加“你的活动任务”标题模板，复用公告状态、稳定帧和已校准关闭坐标。识别成功后关闭任务弹窗，再继续主菜单流程；每日、每周任务及其他公告处理保留。

模板只包含固定标题，不依赖会变化的任务名称、奖励或进度。只有 OCR 任务文字或没有关闭坐标校准时，不新增点击。

验证：当时本机完整测试 257 项、新 EXE 的 61 组截图回放及 GUI、OCR/运行库自检通过。已使用实际 EXE 完成一次活动任务自动关闭并识别主菜单的实机验证；该次只发送一次关闭点击，没有匹配或新增对局。未重新进行长时间连续对局。
