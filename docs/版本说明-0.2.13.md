# 0.2.13 版本说明

日期：2026-11-04。

新增两个独立勾选项，位于“运行设置 → 运行与窗口”：

- **达到固定局数后自动关闭助手**：按本次运行完成的局数计数，完成设定局数并回到大厅后退出助手。未勾选时保留原有达到局数后停止、显示窗口的行为。
- **按自定义时间段自动启动和关闭**：每天按本机时间执行，支持跨午夜。保存时登记当前登录用户的 Windows 每日任务；开始时间自动打开助手并运行，结束时间停止操作并退出助手。

**两项同时开启时，时间段优先，忽略局数上限。** 例如同时设置 3 局和 08:00–15:00，会运行到 15:00，达到 3 局继续运行。

时间段结束不等待当前对局结束，按原有中断逻辑保存未完成记录；暂停时也会到时退出。仅关闭助手，炉石、战网及电脑保持运行。两个选项默认关闭，旧设置、校准和记录继续使用。

电脑需开机并已登录到可操作游戏的桌面，不会自动唤醒电脑。停止按钮取消本次等待；取消时间段勾选并保存会删除每日启动任务。重复启动使用同一助手窗口，避免同一目录多实例同时操作。

验证覆盖每日与跨午夜边界、时间段优先、局数结束退出、手动停止不退出、暂停后到时停止、取消等待和配置校验。424 项本机测试及打包程序验证通过，实际创建并删除了隔离目录的 Windows 计划任务。

2026-11-05，用户反馈定时开启已在本机测试成功。该反馈确认定时启动环节；固定局数后退出和完整时间段结束仍以自动化检查为主，尚未补充整段实机验收。
