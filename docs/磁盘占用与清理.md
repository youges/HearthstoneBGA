# 磁盘占用与清理

便携程序本体只有数百 MB。长期运行的动作截图，以及开发时整份复制截图目录的历史备份，可能远大于程序本体。

## 必须保留

- `HearthstoneBGA.exe` 和整个 `_internal`：程序与依赖。
- `data/settings.json`：运行设置；`data/matches.sqlite3`：对局记录。
- `profiles` 和 `assets`：布局校准、识别模板及界面资源。
- 对局数据库引用的结算截图、正在调查的问题截图和回归测试素材。

## 可优先整理

关闭助手后，优先删除旧版本安装包、废弃构建缓存和重复备份。不要误删运行依赖或仍在使用的校准模板。普通动作截图可以按需要删减，但删除后，旧日志中相应的图片路径将无法再打开；保留数据库不代表所有历史动作截图都还在。

0.2.4 的开发构建流程会先暂存便携版数据。成功构建、恢复并逐文件核验后清除完整临时副本，只保留最近三份设置、数据库、校准的精简备份。失败时保留完整数据以便恢复。运行程序不会据此自动清理截图，也没有新增 GUI 清理按钮。

公开打包使用独立干净目录，仅包含程序、默认配置、参考布局、文档和依赖，不会把个人截图、日志和对局数据库打进去。
