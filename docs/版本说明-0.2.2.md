# 0.2.2 更新说明

2026-10-18，开发测试版。

修复同一回合手中有多张指向性法术时，只能用出一张的问题。

原来每个回合只允许三次手牌读取，成功出牌后仍沿用已消耗的额度，前面的读取重试可能耗尽该回合的额度。

现在确认手牌数量稳定减少、且目标选择箭头消失后，重新读取剩余手牌的位置，清空旧跳过位置并重置读取额度。没有成功施放时仍限制重试；箭头仍在时先完成目标选择，避免直接使用下一张。

保留每回合总动作上限。打包自检增加同一招募阶段连续使用五张法术的两种模拟场景：直接拖到目标，以及拖动后再点击目标。该自检不操作真实游戏，不能替代真实多张法术的对局测试。

153 项本机回归测试通过，包括先选效果、再等待指向箭头、选随从后继续下一张，失败时不刷新额度，以及目标未完成时不启动下一张。打包程序的 GUI、OCR 和自有全屏窗口检查通过。

本次整合已有的全屏适配修复和战网路径检测。7/7 金币被识别成 L/L 的问题仍未解决，可能漏掉一回合操作；未知牌型会跳过。尚未完成真实多张指向性法术及跨电脑完整对局验收。

更新前关闭旧助手，备份 data、profiles 和校准模板。完整解压新版，在新电脑先用只观察模式检查。便携包包含程序与运行库，不能只保留 EXE。
