# 0.2.0 更新说明

2026-10-18，开发测试版。

## 新增

- 自动检测战网路径，包括失效旧配置、运行中客户端、注册表和常见安装目录。
- 设置页增加“自动检测”按钮，打开设置和启动时均会检查路径。
- 自动适配游戏窗口比例、显示器工作区及物理像素坐标；默认开启，可在设置中关闭。
- 小尺寸模板增加像素取整误差匹配，保留原阈值。
- 战网按钮可通过游戏名和唯一启动文字辅助定位。
- 发布包与个人运行数据分离。

## 验证

140 项测试通过。几何规划覆盖普通宽屏、超宽屏、4:3、竖屏和负坐标副屏。真实游戏截图回放覆盖 1280×720、1360×765、1920×1080、2560×1440、3840×2160。实机自有窗口测试在 125% DPI 下从 1250×813 调整到 1701×956；第二次检查不重复改变尺寸。实际战网进程路径和注册表检测均通过。

这些验证没有代替另一台电脑上的完整对局。请先用只观察模式检查，再运行一局。

## 升级

关闭旧程序，备份旧目录下 `data` 和 `profiles`。新版便携包先解压到新目录，再按需复制自己的设置与记录。不要在运行时直接覆盖 `_internal`。默认发布设置为只观察，避免在新电脑上未检查就发送操作。

## 发布内容

Windows 便携 ZIP、源码 ZIP、SHA-256 校验文件。使用说明和功能文档随包提供。公共包不含个人日志、对局数据库、用户截图或实际安装路径。
