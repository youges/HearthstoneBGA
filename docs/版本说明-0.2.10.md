# 0.2.10：混合手牌中的随从确认与出牌

功能完成日期：2026-10-25。本小版本随 0.2.11 于 2026-10-26 同步到公开仓库。

修复手牌法术与随从混合时，其他牌的轮廓候选数量改变，导致已识别随从被作废和跳过的问题。悬停前保存候选内部图像描述，收起说明后连续两帧核对附近候选的位置与图像；其他候选数量变化不单独使当前牌失效。图像改变、移位或仅有一帧确认时不使用旧识别结果。

优先读取带酒馆旗标的候选，但仍以说明文字证明随从类型。具备图像描述时最多读取十个不同候选；没有图像描述时保留三次上限。成功出牌后刷新读取额度和位置，近似坐标抖动不会反复读取同一候选。

以场上随从数量增长补充确认出牌，支持手牌总数未下降时继续处理；原随从图像仍在手中时，候选数量单独下降不作为成功依据。

验证：当时本机完整测试 337 项、冻结 EXE 的 81 组截图回放及 GUI、OCR/运行库自检通过。覆盖两组现场候选数 2→3、1→4 的失败画面、真实 OCR、连续两帧核对、候选变化和场面增长后的继续操作。冻结引擎另使用合成观测验证流程，没有发送真实游戏输入。尚未完成新版混合手牌场景的专项实战验收；私人截图不公开，公共 CI 跳过对应测试。
