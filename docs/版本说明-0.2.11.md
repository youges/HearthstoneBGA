# 0.2.11：主厨甄选的随从目标选择

功能完成日期：2026-10-25，公开同步日期：2026-10-26，开发测试版。本次同时包含 0.2.10 混合手牌修复，两版各有独立说明。

修复“主厨甄选”被误判为“发现”效果、打出后没有选择随从的问题。根据“选择一个随从，获取相同类型的另一张随从牌”的完整效果识别为 `targeted_acquire`；限制悬停说明读取范围，排除下方其他手牌的“发现”文字。只识别到卡名或文字不完整时不据此施法。

优先向友方随从施放，没有友方随从时可使用已识别的酒馆随从。目标箭头出现后选择高亮的合法友方或酒馆目标；已知场上数量时按随从槽位中心点击。普通增益法术仍遵循原目标范围。

目标箭头存在时阻止升本和其他招募操作，不把暂时检测不到手牌当成施法成功。目标选择结束需连续两帧确认；获取随从替换法术、手牌总数不变时也能结束等待，刷新手牌读取额度并继续操作。

验证：本机完整测试 362 项、冻结 EXE 的 85 组截图回放及 GUI、OCR/运行库自检通过。包含两次真实手牌说明、两次目标画面的多分辨率验证，以及目标范围、下方文字排除、同手牌数量的完成反馈。冻结引擎自检覆盖目标选择与箭头存在时阻止升本；回放和合成观测没有发送真实游戏输入。新版主厨甄选的实际施放仍待实战确认，不能将上述验证视为专项实战验收。私人截图不公开，公共 CI 跳过依赖它们的用例。

公开包默认保留只观察模式，异常自动认输默认关闭。更新时先备份自己的数据、校准和模板，关闭旧助手后将新版完整解压到新目录；先确认识别正确，再开启真实操作。
