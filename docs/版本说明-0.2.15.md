# 0.2.15：星期与指定日期定时、直接输入及滚动选择时间

日期：2026-11-12。

“运行设置 → 运行与窗口”新增周一至周日七个勾选框，可选择任意多天，每周按所选日期和统一的开始、结束时间运行。默认七天全选，旧版配置自动保留每天运行的行为。

定时日期模式可切换为“指定日期（不重复）”，从日历添加一个或多个具体日期，也可移除所选日期。该模式只在列表中的日期执行，不受星期勾选影响；所有日期结束后停止等待，显示重新设置日期的提示。两种模式各自保存选择，切换时不会清空另一种模式的日期。

开始和结束时间改为普通文本框，可直接输入 `08:30`、`15:00`，也接受 `8:30` 并规范为 `08:30`。点击“滚动选择…”可打开小时、分钟双列选择器，支持鼠标滚轮、上下拖动、点击数字及上下方向键。点击“确定”使用选中时间；取消保留原来的输入。无效时间会在保存时提示。

例如勾选周一至周五、设置 08:00–15:00，则周末不会启动。只选周一、设置 22:00–03:00，则周一晚上开始、周二凌晨结束；跨午夜按开始日计算，包括周日跨到周一的情况。

开启定时运行时必须至少勾选一天或添加一个指定日期。修改模式、日期或时间并保存，会更新 Windows 每周或一次性计划任务；登记失败时保留此前已保存的设置。非选中日期打开助手会等待下一次选中日期，到结束时间仍立即停止并关闭助手。时间段与固定局数同时开启时，继续以时间段为准。

此功能使用电脑本地时间，电脑需要开机并已登录；不会自动唤醒电脑。

验证：469 项测试通过，覆盖跨日跨周、指定日期不重复、日期过期、旧设置兼容、保存失败回退、时间输入及滚动选择交互。Windows 实际接受了两种模式生成的计划任务；测试触发器全程禁用，测试任务检查后已删除。
