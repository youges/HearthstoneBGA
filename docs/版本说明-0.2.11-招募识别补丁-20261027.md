用户反馈手牌堆满后程序不再操作，并在排查期间手动处理过手牌。后续最新画面中手牌已减少，但程序仍持续报告 `unknown`。日志显示这一局从英雄选择结束后就无法可靠识别招募阶段，发现和战斗界面偶尔能识别。不能把用户先前手动出牌算作本次程序修复的实测。

模板与招募锚点已同步到当前便携版，使用程序已有的重新读取校准指令载入。原校准分别备份在 `data/qa-20261027-full-hand/source-profile-before.json` 与 `installed-profile-before.json`。仅增加招募模板分支，其他个人点位和区域保留，运行设置保持原值；未直接改写对局数据库。
