# 0.2.1 更新说明

2026-10-18，开发测试版。

修复开启自动适配后，正常的 1920×1080 全屏游戏被判定为超过桌面工作区，尝试缩小窗口并暂停的问题。

现在会同时检查窗口样式与物理客户区：符合校准比例的全屏保持原尺寸，普通窗口继续按桌面可用区域调整。全屏比例不符合校准时，提示切换窗口模式。

146 项测试通过。本机 1920×1080、125% DPI 下，打包自检覆盖普通窗口调整及全屏窗口保持不变。1440p、4K、不同任务栏位置和负坐标显示器通过几何与适配接口回归测试；尚未在这些真实屏幕上进行整局验收。

本机真实炉石运行日志确认全屏客户区保持 1920×1080、未调整尺寸，并已观察到该局结算和返回大厅记录。公共 CI 不包含私人实机截图，会跳过对应回放用例。程序仍处于开发测试阶段，基础策略、不同选择布局及未知法术仍有局限。

更新时关闭旧助手，备份自己的 data、profiles 和校准资源，将新版完整解压到新目录。新下载的发布包默认开启自动适配和只观察；请先确认识别结果，再开启真实操作。不要在程序运行时覆盖文件。
