# 0.2.5：连续运行中的结算识别修复

功能完成日期：2026-10-21。本小版本的改动随 0.2.9 同步到公开仓库。

连续完成六局后，第七局因结算“等级”标签存在细微像素差异而识别超时。结算模板现增加宽高各一像素的匹配候选，保留原搜索区域与阈值；其他状态不新增该原生尺寸容差。现场匹配得分由约 0.831 提升至约 0.929。

截图回放清单可要求 `trusted: true`，报告输出视觉可信状态，防止将 OCR 名次提示当作可执行的结算识别。

验证：当时本机完整测试 193 项通过，新 EXE 的 GUI、OCR/运行库自检及 16 组截图回放通过。覆盖失败截图四种尺寸、合成正负例，以及十二局结算后再次匹配的离线模拟。离线模拟不等同于十二局真实对局，长期稳定性仍需实际运行观察。
