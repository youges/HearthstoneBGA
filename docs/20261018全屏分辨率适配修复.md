# 全屏分辨率适配修复

2026-10-18。本地修复版本 0.2.1，基于 0.2.0。

## 问题及原因

启用自动适配后，1920×1080 全屏炉石可能提示“窗口未接受适配尺寸”并暂停。
旧实现将所有窗口与扣除任务栏后的工作区比较，错误地要求全屏游戏缩小至工作区。

## 修复行为

- 检查窗口样式和物理客户区是否覆盖整个显示器，区分全屏与普通窗口。
- 符合当前校准比例、且尺寸足够的全屏画面直接使用，不恢复、不缩小窗口。
- 普通窗口仍按桌面工作区调整，保留任务栏和窗口边框空间。
- 全屏比例不符合校准时明确提示切换窗口模式，不强行调整游戏显示模式。
- 日志增加 `mode`（fullscreen/windowed）与 `monitor_area`，便于排查。

## 验证范围

回归测试覆盖 1080p、1440p、4K 几何，以及底部、左侧、顶部任务栏和负坐标显示器。
打包自检同时验证本机普通窗口适配及全屏窗口保持不变。
更高分辨率几何测试不代表已在对应真实显示器上完成游戏验收。
